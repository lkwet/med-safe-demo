# MedSafe public demo mirror

This repository hosts a static fallback for **HacKU 2026 Group 51 — Bauhinia Spheal**.

The canonical project, team attribution, documentation and development history are in [yc-eagle/med-safe](https://github.com/yc-eagle/med-safe). This mirror does not replace the team repository.

Product files were built from team commit `845a4d739e0a91755ff83627338c15d4198b60f0`. Their contents are unchanged in the subsequent team commit `f38b5ee8382b88b5ff05752f702b780c61c5d3b9`.

The site opens in English and provides Mandarin and Cantonese selectors. The app includes sourced medicine information and a limited, draft rule set; it does not establish that a medicine combination is safe.

Use **Prepare for offline use** while connected and wait for verified completion before testing offline. Browser speech recognition needs internet; local reading depends on available device voices. No patient photos or recordings are included in this repository.

Third-party OCR and language conversion licenses are included in `vendor/`. Clinical references and data provenance are accessible from the app.

This is a deployment branch. Do not merge its static output into the canonical source branch.
